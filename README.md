# Effective Python Examples

This repository contains code examples and tests from the book "Effective Python: 90 Specific Ways to Write Better Python" by Brett Slatkin.

## Structure

The examples are organized by topic, mirroring the structure of the book. Each subdirectory typically corresponds to a chapter or a major concept discussed in the book.

For instance, the `concurrency` directory contains examples related to concurrency as demonstrated in the book.

## Usage

To run a specific example, navigate to its directory and execute the Python script:

```bash
cd concurrency
python3 stream_encryption_hashing.py
```

## About the Book

"Effective Python" provides practical advice and best practices for writing robust, maintainable, and efficient Python code. It covers a wide range of topics, from basic idioms to advanced concurrency and metaprogramming.
